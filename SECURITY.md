# Signaler une faille de sécurité

Notre promesse repose sur un point : vos photos et vos fichiers restent chez vous. Si vous trouvez une faille dans l’un de nos dépôts, dans le site ou dans le système de la box, merci de nous la signaler en privé.

## Comment faire

1. Ouvrez l’onglet **Security** du dépôt concerné.
2. Cliquez sur **Report a vulnerability** (signalement privé).
3. Décrivez ce que vous avez trouvé, comment le reproduire et ce qu’un attaquant pourrait en faire.

N’ouvrez pas d’issue publique pour une faille : elle serait visible de tous avant d’être corrigée.

## Ce que nous faisons ensuite

Nous accusons réception, nous vérifions le problème, puis nous vous disons comment et quand nous le corrigeons. Si vous le souhaitez, nous vous citons dans les notes de la correction.
